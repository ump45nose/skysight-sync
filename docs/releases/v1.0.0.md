# Skysight Sync v1.0.0

多台 Mac，一份 Codex 原生电脑历史。

- 通过私有 SFTP 汇集各设备的 Skysight Markdown 摘要，无须设备同时在线。
- 按 UTC 自然 6 小时窗口归并；保留各设备内容和全部原文，不调用模型。
- 北京时间 09:00 每日后台运行，登录补做；提供状态、只读预览与原生历史恢复。
- 支持中断恢复、迟到摘要、本机删除抑制和 SSH 严格主机验证。
- 独立应用图标：1024px 透明 PNG 与 macOS ICNS；MIT 许可证。

## 下载与安装

下载 `skysight-sync_1.0.0_darwin_arm64.tar.gz`，按仓库 README 配置私有 SFTP 中转与两台设备。`SHA256SUMS` 用于校验下载完整性。压缩包包含程序、说明、许可证、依赖声明和图标。

发布目标为 **Apple Silicon Mac**。程序未经过 Apple 公证。原生兼容性已在 Codex `26.1007.71326` 验证；客户端升级后应先执行 dry-run。Windows 服务和原始操作事件同步不在此版本范围。

已有安装无需重新初始化，也不要覆盖自己的配置或状态文件。
