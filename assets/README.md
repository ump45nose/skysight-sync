# 应用图标

双向连接的时间线组成 S 形标记，用于 Skysight Sync 的项目主页和发布包。

- `icon.png`：1024 × 1024 PNG，圆角底板外透明。
- `SkysightSync.icns`：macOS 图标，包含 16–1024 像素分辨率。

图标由 Codex 内置图像生成工具生成，再使用 macOS `sips` 缩放、`iconutil` 转换格式；未使用外部品牌图形。随项目采用 MIT 许可证。它是品牌资源；后台服务不会新增 Dock 窗口。

## 生成提示词

```text
Use case: logo-brand
Asset type: original 1024 x 1024 macOS app icon for Skysight Sync, a quiet background tool that unifies computer-history summaries across devices.
Primary request: one polished, immediately recognizable application icon. A bold continuous ribbon built from two interlocking curved paths forms a compact S / synchronization loop, with two small terminal nodes suggesting connected timelines. The mark should feel calm, precise, and trustworthy.
Style: minimal geometric design with a restrained soft bevel, not a detailed illustration. Sky-blue and pale icy-blue paths on a deep midnight-blue rounded-square tile. Subtle lighting, crisp silhouette, generous breathing room. Center the mark; it must read at 32 pixels.
Composition: single icon, square canvas, rounded tile filling about 88 percent of the canvas with transparent space outside the tile. No surrounding mockup or extra objects.
Constraints: genuinely transparent outside the rounded tile. No text, letters, watermark, Apple logo, OpenAI logo, eyes, clouds, screens, tiny details, or decorative sparkles. Original standalone identity, not a variation of another brand.
```
